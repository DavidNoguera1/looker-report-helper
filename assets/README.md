# Brand assets

Original Looker Report Helper artwork, released under this repository's MIT license. The dashboard and connector represent an agent-to-report connection. This is not Google's logo and does not imply Google endorsement.

- `logo.svg`: editable vector artwork.
- `logo.png`: 512 x 512 export for the plugin and README.
- `icon.png`: 128 x 128 composer icon.

Regenerate all three with `python scripts/build_logo.py`. This optional development command needs Pillow; the MCP server does not. The same geometry produces the SVG and antialiased PNG exports.
